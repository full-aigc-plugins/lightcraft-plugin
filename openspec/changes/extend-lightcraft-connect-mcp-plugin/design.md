## Context

扩展登记，未实施。源码与固定制品能力必须分开。

## Goals / Non-Goals

Goals: 连接模式、桌面库占用与会话身份。Non-Goals: 不修改基础变更验收标准，不从离线测试推导平台、RAW 或宿主通过。

## Decisions

按固定版本、执行模式、素材/制品摘要和明确目标绑定证据；复用版本化回执和任务状态，不建立第二套原生解释器。失败和 UNKNOWN 保留，外部安装/发布按对应授权。

## Risks / Trade-offs

依赖、模型或设备缺失时保留 BLOCKED/NOT_RUN；不能用新文档关闭运行门禁。

## Migration Plan

先建立失败回归，再实现并验证各门禁；兼容旧记录并保留人工修改。

## 2026-10-08 上游执行边界

上游固定原生 Connect 客户端对网络失败会重发同一请求，修改请求也在其中。插件不能在 UNKNOWN 后自动续跑，也不能以 initialize 成功代替桌面库可达；接入必须消费技能源的新只读会话回执，并分别记录协议启动、库查询和远端会话身份。已公开技能快照保持不可变；技能源尚未发行的新资源不得被伪装成已锁定版本。后续适配先完成回执消费回归，再通过实际来源升级接入，不直接修改受管技能。
